# Code of Conduct

This project follows the **[Bioconductor Code of Conduct](https://bioconductor.github.io/bioc_coc_multilingual/)**
(current version 1.5.0, 2026-03-18), which applies to every Bioconductor
communication channel and code contribution — including this repository's
issues, pull requests, and discussions.

It is adopted by reference rather than copied here, so it cannot drift out of
date relative to the community policy it is meant to mirror. The canonical text
is maintained (and translated) at
<https://bioconductor.github.io/bioc_coc_multilingual/>.

In short: harassment, intimidation, and bullying are not tolerated, and
contributions are expected to come from identifiable accounts.
